# SameGame 消消乐

终端版 SameGame（Clickomania）：点击 2 个以上相连的同色格子消除，看你能拿多少分。

## 玩法

- 棋盘默认 10 行 × 15 列，5 种颜色（A–E）。
- 每次选择一组上下左右相连的同色格子（至少 2 个）消除。
- 消除后：上方格子下落填补；空列整体向左塌陷。
- 得分：消除 n 个得 `(n-2)^2` 分（消 2 个得 0 分，所以别贪小）；清空整盘额外 **+1000**。
- 没有可消除的组时游戏结束。

## 用法

```bash
python3 -m samegame                 # 人机对战（需要终端）
python3 -m samegame --auto          # AI 自动演示 10 局
python3 -m samegame --auto --games 20 --seed 42
python3 -m samegame --auto --verbose  # 打印每步棋盘
python3 -m samegame --rows 8 --cols 12 --colors 4  # 自定义棋盘
```

人机模式下：输入组编号消除，或输入「行 列」坐标；`q` 退出。

## AI

1 步贪心：每次选最大的组；大小相同时优先能消光某种颜色的组（清色往往带来连锁大组）。
无深层搜索，不看未来塌陷后的连锁。

## 已知局限（诚实版）

- AI 只是 1 步贪心，不做多步搜索；懂"留大组、清颜色"套路的人类通常能赢更多。
- 贪心 AI 几乎清不干净整盘（实测 10 局清空 0 局）；想拿 +1000 需要更聪明的搜索。
- 字母 A–E 表示颜色，无彩色图形界面；无存档/悔棋/网络对战。
- Python 3.10+，纯标准库。
